** Overview

=personal/= には、ユーザーやデバイスに固有のオーバーレイを置きます。

これらのファイルには次の性質があります。

- *バージョン管理から除外される* （あるいは共有コミットには含めない）
- *編集して安全* — 変更しても他のユーザーには影響しません
- *モジュールの前にロードされる* — =init.el= のステップ 9 で読み込まれ、 =modules.el= を require するステップ 10 より先に走ります。
  パス変数などの上書きは、後から評価される =defvar= や =defcustom= が既存の値を上書きしないことで効きます。
  リーダーキーの割り当てのように、モジュールが整ってから実行したいものは =after-init-hook= の depth 10 に回します

*なぜ分けるのか*

フォント、API キーの参照先、macOS 固有の設定 — これらは「その人のその機械」でしか意味を
持ちません。共有される =lisp/= に混ぜると、他の環境で不可解な挙動を引き起こします。境界を
はっきり引いておけば、共有部分だけを安心して git に載せられます。

主なファイルは次のとおりです。

| ファイル | 目的 |
|------+---------|
| =personal/user.el= | 全マシン共通の個人設定、`my:wsl-p'、デバイスファイルのロード |
| =personal/<login>.el= | 識別情報、 =GPG_KEY_ID= の export、 =my:d:org= の上書き、フォント、UI・LSP スイッチ、mu4e |
| =personal/personal-ime.el= | IME（sis）状態の nano-modeline・dirvish への表示 |
| =personal/personal-hugo.el= | Hugo ブログ（ =all-posts.org= ）のタグ設定と capture |
| =personal/device-darwin.el= | macOS の IME、マウス／スクロール、Keychain。Apple Music の操作は =dev-apple-music= を追加で読み込む |
| =personal/device-wsl.el= | WSL のリーダーキー切替（ =C-c SPC= ）、クリップボード連携、Explorer 起動、既定ブラウザ (=wslview=) |
| =personal/personal-messages.el= | macOS Messages.app のアーカイバ |
| =personal/personal-ai.el= | Org Babel と Claude API の統合（どこからも自動では読み込まれない。使うときは =(require 'personal-ai)= する） |
| =personal/personal-llm.el= | ローカル LLM ルーター（=~/.local/bin/localllm=）との統合（=my/llm-run=） |

  ;;; personal/user.el --- 共有の個人設定 -*- lexical-binding: t; -*-
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: personal
  ;;
  ;;; Commentary:
  ;; 本設定を使うすべてのマシンで読み込まれる、共有の個人設定。
  ;;
  ;; personal-messages は `with-eval-after-load 'org' + `locate-library' のガード +
  ;; `run-with-idle-timer' により安全にロードする。`run-with-timer' をロード時（t=0）に
  ;; 無条件で発火させると、org の初期化との競合状態を生むためである。
  ;;
  ;; `run-with-idle-timer' の REPEAT 引数は `t' ではなく数値（秒）でなければならない。
  ;; `t' は「Emacs がアイドルになるたびに実行」を意味し、意図よりはるかに高頻度で
  ;; 発火する。文書化された意図に合わせ 600（10 分）にしている。
  ;;
  ;; ui-visual-aids、orgx-typography、orgx-brain、orgx-citar、ui-macos を
  ;; `my:modules-extra' に追加する処理は、
  ;; core/ ではなくここに置く。
  ;; core モジュールが上位層（ui、orgx）のモジュール名を注入してはならない。これは個人の
  ;; 表示上の選択であり、personal 層に属する。本ファイルは init.el のステップ 9 で、
  ;; modules.el が require されるステップ 10 より前にロードされるため、my/modules-load が
  ;; 走る時点で extra リストは完全に構築済みである。
  ;;
  ;;; Code:

  ;; user-full-name と user-mail-address は defcustom（simple.el）である。
  ;; setter と型検証を尊重するため setopt を用いる。
  (setopt user-full-name    "YAMASHITA, Takao"
          user-mail-address "tjy1965@gmail.com")

  ;; 任意の UI / org モジュール拡張。
  ;;
  ;; 理由: これらは個人の表示上の選択（視覚補助、タイポグラフィ、macOS の仕上げ）であり、
  ;; 共有ポリシーではない。personal 層でここに宣言することで、core/ モジュールが上位層
  ;; （ui、orgx）への参照をモジュールのロードリストに注入してはならない、という規則を保つ。
  ;;
  ;; これは `modules.el' が require される前に走る: init.el はステップ 9 で
  ;; personal/user.el をロードし、ステップ 10 で modules を require するため、
  ;; my/modules-load が最終リストを走査する時点で my:modules-extra は構築済みである。
  ;; orgx-roam-ui は意図的に含めない。org-roam-ui はモジュールのロード時に
  ;; (straight-use-package 'org-roam-ui) を行い、with-eval-after-load 'org-roam 経由で
  ;; アイドルタイマーを仕込む。これが org-roam -> org を起動直後に引き込む経路になるため、
  ;; Org の遅延ロードを優先してここから除外した。UI が必要になったら M-x org-roam-ui-open
  ;; を実行する（autoload されているのでその場でロードされる）。
  ;; グラフを常用する運用に戻す場合は orgx-roam-ui をこのリストへ戻す。
  (setq my:modules-extra
        (delete-dups
         (append my:modules-extra
                 '(ui-visual-aids
                   orgx-typography
                   orgx-brain
                   orgx-citar
                   ui-macos))))

  ;; ロケールとエンコーディングの初期化。
  ;;
  ;; `set-language-environment' は `prefer-coding-system' より前でなければならない。
  ;; "Japanese" を指定して呼ぶことで、日本語テキスト検出のための内部コーディングシステム
  ;; 優先順位リスト（EUC-JP、Shift_JIS、UTF-8）が調整される。
  ;; 続く `prefer-coding-system' が utf-8 をそのリストの先頭に昇格させ、読み書きの
  ;; 双方で UTF-8 が優先されることを保証する。
  ;;
  ;; 従来の `set-locale-environment "UTF-8"' はプロセスのロケールを設定するだけで、
  ;; Emacs 内部のコーディングシステム優先順位リストを調整しなかった。そのため日本語
  ;; ファイルの検出が不安定だった。
  ;;
  ;; コーディング規則 §6: これらは defcustom ではないため、素の setq / 関数の直接呼び出しが
  ;; ここでは正しい。
  (leaf my:locale
    :straight nil
    :init
    (set-language-environment "Japanese")   ; adjusts coding-system priority list
    (prefer-coding-system 'utf-8)           ; promotes utf-8 to head of priority list
    (set-default-coding-systems 'utf-8)
    (set-terminal-coding-system 'utf-8)
    (set-keyboard-coding-system 'utf-8)
    (set-file-name-coding-system 'utf-8)
    (set-selection-coding-system 'utf-8)
    (setenv "LANG" "en_US.UTF-8"))

  ;; WSL 判定ユーティリティ
  ;;
  ;; WSL (Windows Subsystem for Linux) 上の `system-type' は素の Linux と同じ
  ;; `gnu/linux' であり、`system-type' だけでは区別できない。WSL は環境変数
  ;; `WSL_DISTRO_NAME'（wsl.exe が各ディストロ起動時に設定する）で確実に判定できる。
  ;;
  ;; この関数はデバイスファイルのロード（直後）と、後段の `personal/ac1965.el'
  ;; （`my:d:org*' 等のパス分岐）の両方から参照されるため、両者より前に位置する
  ;; 本ファイル（`personal/user.el'）内で定義する。
  (defun my:wsl-p ()
    "現在 WSL 上で動作していれば non-nil を返す."
    (and (eq system-type 'gnu/linux)
         (getenv "WSL_DISTRO_NAME")))

  ;; デバイス固有の設定をロードする
  ;;
  ;; WSL は `system-type' が `gnu/linux' と衝突するため、`my:wsl-p' を優先判定し、
  ;; 該当すれば `device-wsl.el' を、そうでなければ従来どおり
  ;; `device-<system-type>.el' をロードする。
  (let* ((personal-dir
          (expand-file-name "personal/"
                            (or (bound-and-true-p my:d) user-emacs-directory)))
         (device-file
          (expand-file-name
           (if (my:wsl-p)
               "device-wsl.el"
             (concat "device-" (symbol-name system-type) ".el"))
           personal-dir)))
    (when (file-exists-p device-file)
      (load device-file nil 'nomessage)))

  ;; personal-messages: macOS の Messages.app を org-roam にアーカイブする
  ;;
  ;; ロード戦略:
  ;;   1. `locate-library' でガードする — ファイルが無ければ静かにスキップ。
  ;;   2. `with-eval-after-load 'org' により、Org の準備完了までロードを遅延する。
  ;;   3. `run-with-idle-timer' の REPEAT には数値（600 秒 = 10 分）を渡し、
  ;;      アーカイブが 10 分のアイドル期間につき最大 1 回になるようにする。
  ;;      注意: REPEAT に `t' を渡すと「Emacs がアイドルになるたびに発火」となり、
  ;;      頻度が高すぎる。間隔には必ず正の数値を使うこと。
  ;;
  (when (locate-library "personal-messages")
    (with-eval-after-load 'org
      (when (require 'personal-messages nil t)
        (when (fboundp 'personal-messages-archive)
          ;; 初回はアイドル 120 秒後。以降は 600 秒（10 分）ごとに繰り返す。
          (run-with-idle-timer 120 600 #'personal-messages-archive)))))

  ;; personal-llm: ローカル LLM ルーター（~/.local/bin/localllm）統合
  ;;
  ;; personal-messages と異なり org 本体には依存しない（Org-roam バッファからの
  ;; 呼び出しでもリージョン／バッファ文字列を渡すだけで org 固有関数を使わない）
  ;; ため、`with-eval-after-load 'org' で遅延させる必要はない。`locate-library'
  ;; でガードし、ファイルが無ければ静かにスキップする。
  (when (locate-library "personal-llm")
    (require 'personal-llm nil t))

  ;; ---------------------------------------------------------------------------
  ;; 自動保存の除外設定（個人ポリシー）
  ;; ---------------------------------------------------------------------------
  ;; 自動保存の対象外とするファイルを設定する。
  ;; コアの既定で既に除外済み: gpg age enc pem p12 pfx。
  ;; 個人的な除外はここに追加する。

  ;; 追加のファイル名パターンを除外（フルパスに対して照合）:
  (setopt core-autosave-exclude-name-patterns
          '("\\.authinfo"         ; credential files (plain or encrypted)
            "\\.netrc"            ; legacy netrc
            "/tmp/"                ; temp files — let OS manage them
            "\\.bak\\'"           ; already-a-backup files
            "COMMIT_EDITMSG\\'"   ; git commit message buffers
            "MERGE_MSG\\'"
            "rebase-merge/"
            "\\.log\\'"))         ; log files — append-only, save noise

  ;; メジャーモードによる除外:
  (setopt core-autosave-exclude-modes
          '(erc-mode               ; IRC — messages are server-side
            circe-mode
            term-mode              ; terminal emulators — no file backing anyway
            vterm-mode
            eshell-mode
            sql-interactive-mode)) ; SQL REPL output

  (provide 'user)
  ;;; personal/user.el ends here
#+end_src

=ac1965.el= は =(require 'personal-ime)= で読み込みます。読み込む位置は、分離前にこのコードが
あった位置のままです。読み込み順に敏感な箇所（ =dirvish= の =NOERROR= の =require= など）の理由は、

#+NAME: personal-ime-el
#+begin_src emacs-lisp
  ;;; personal/personal-ime.el --- IME 状態のモードライン表示 -*- lexical-binding: t; -*-
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: personal
  ;;
  ;;; Commentary:
  ;;
  ;; IME（sis）の状態を、nano-modeline と dirvish の mode-line に表示する。
  ;;
  ;; 本ファイルの責務:
  ;; - `sis-change-hook' で更新するグローバルなキャッシュ `ac1965--sis-indicator' を持つ
  ;; - dirvish の mode-line に `ime' セグメントを登録する
  ;; - `ui-nano-modeline-ime-function' に、キャッシュを返す関数を渡す
  ;;
  ;; 名前は旧来の ac1965-- の接頭辞のまま（core-dired.el や README の記述が参照するため）。
  ;;; Code:

  ;; ---------------------------------------------------------------------------
  ;; nano-modeline の IME インジケータ
  ;; ---------------------------------------------------------------------------

  ;;
  ;; sis--current は sis-global-respect-mode の pre/post-command-hook ハンドラ
  ;; （sis--save-to-buffer = sis--get）が更新する。
  ;;
  ;; sis-change-hook は値が変化したとき sis--update-state の内部で発火する。
  ;;
  ;; キャッシュ変数は nano-modeline の :eval ブロックがフレームごとに読む。
  ;; プロセス起動のオーバーヘッドはゼロである。
  ;;
  ;; defvar-local ではなく defvar とする理由:
  ;; sis-change-hook は IME 切替を起こしたバッファで発火する。
  ;; バッファローカル変数ではそのバッファしか更新されないが、
  ;; グローバル変数なら直ちにすべてのバッファへ反映される。
  ;;

  (defvar ac1965--sis-indicator ""
    "Cached IME indicator string for the nano-modeline right segment.
  Updated by `ac1965--sis-update-indicator' via `sis-change-hook'.
  Values: \" A\" (english), \" あ\" (other), \"\" (unknown/unset).
  Global so all buffers reflect the current IME state.")

  (defun ac1965--sis-update-indicator ()
    "Update `ac1965--sis-indicator' from the current `sis--current' value.
  Attached to `sis-change-hook'; called whenever sis detects an IME switch."
    (setq ac1965--sis-indicator
          (pcase (and (boundp 'sis--current) sis--current)
            ('english " A")
            ('other   " あ")
            (_        ""))))

  (with-eval-after-load 'sis
    (add-hook 'sis-change-hook #'ac1965--sis-update-indicator))


  ;; ---------------------------------------------------------------------------
  ;; dirvish 用 IME mode-line セグメント
  ;; ---------------------------------------------------------------------------

  ;;
  ;; dirvish は編集バッファの nano-modeline パイプラインを通らない独自の
  ;; mode-line（`dirvish-mode-line-format'、core/core-dired.el の
  ;; `core-dired--activate' で :right に `ime' を追加済み）を持つため、
  ;; ウィンドウ最大化時など見た目上の手がかりが少ない状況では dirvish バッファに
  ;; 入った瞬間 IME 状態が分からなくなっていた。
  ;;
  ;; ここでは新たに osascript/macism を呼ぶのではなく、上で定義済みの
  ;; `ac1965--sis-indicator'（sis-change-hook が更新するグローバルキャッシュ）を
  ;; そのまま読むだけのセグメントを `dirvish-define-mode-line' で登録する。
  ;;
  ;; プロセス起動コストはゼロで、編集バッファ側と表示内容も常に一致する。
  ;;
  ;; `dirvish-define-mode-line' はマクロであり dirvish がロード済みである必要がある。
  ;; 本ファイルは modules.el より前（init.el のステップ 9）にロードされ、dirvish 本体は
  ;; その後に core-dired が読み込むため、ここを評価する時点では dirvish は未ロードである。
  ;; そこで `with-eval-after-load' で包み、dirvish のロード後に定義する。
  ;;
  ;; マクロ定義そのものはコンパイル時に展開されるため、バイトコンパイラが
  ;; `dirvish-define-mode-line' を普通の関数呼び出しと誤解しないよう、
  ;; eval-when-compile で dirvish を require しておく。
  ;;
  ;; NOERROR (第2引数 nil、第3引数 t) が必須:
  ;;
  ;; `eval-when-compile' はバイトコンパイル時にしか特別扱いされない。
  ;; 本ファイルのようにインタプリタ実行（非コンパイル）される .el を
  ;; `load' すると、Emacs のロード時 eager macro-expansion がこの
  ;; トップレベルフォームを即座に展開しようとする。
  ;;
  ;; personal/personal-ime.el（ac1965.el から require される）は init.el ステップ9で、modules.el（ステップ10、
  ;; core-dired の `(leaf dirvish :straight t :require nil)' が dirvish を
  ;; 実際にインストールする箇所）より前にロードされるため、この時点では
  ;; dirvish はまだ load-path 上に存在しない。
  ;;
  ;; NOERROR なしだと `(require 'dirvish)' が file-missing で失敗し、
  ;; 本ファイルの残りがロードされなくなる。
  ;;
  ;; NOERROR で「失敗したら nil を返すだけ」にしておけば、この時点では
  ;; require をあきらめて後続の `with-eval-after-load' 登録に進み、
  ;; 実際に dirvish がロードされたときに遅延展開されて正しく登録される。

  (eval-when-compile
    (require 'dirvish nil t))

  (with-eval-after-load 'dirvish
    (dirvish-define-mode-line ime
  			    "Show the cached sis IME indicator (`ac1965--sis-indicator') in dirvish's
  own mode-line. Mirrors the editing-buffer nano-modeline segment so IME
  state (English / Japanese) stays legible while browsing in dirvish,
  including when the frame is maximized. Reads the shared cache only —
  no subprocess is spawned here; `ac1965--sis-update-indicator' (attached to
  `sis-change-hook') is what keeps the cache current."
  			    (when (boundp 'ac1965--sis-indicator)
  			      (string-trim ac1965--sis-indicator))))


  ;; ---------------------------------------------------------------------------
  ;; nano-modeline 用の IME 表示
  ;; ---------------------------------------------------------------------------

  ;;
  ;; モードラインの表示内容（表示項目・フェイス・全体への適用・トグル）は
  ;; ui/ui-nano-modeline.el にある（設計は同ファイルの Commentary を参照）。
  ;; ここには、このマシン固有の入力である
  ;; IME の状態だけを置き、`ui-nano-modeline-ime-function' を通して渡す。
  ;;

  (defun ac1965--sis-indicator-string ()
    "Return the cached IME indicator (`ac1965--sis-indicator') for the modeline."
    ac1965--sis-indicator)

  (setopt ui-nano-modeline-ime-function #'ac1965--sis-indicator-string)

  (provide 'personal-ime)
  ;;; personal/personal-ime.el ends here
#+end_src

#+begin_src emacs-lisp
  ;;; personal/personal-hugo.el --- Hugo ブログの執筆支援 -*- lexical-binding: t; -*-
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: personal
  ;;
  ;;; Commentary:
  ;;
  ;; all-posts.org（ox-hugo の単一ファイル・ソース）の執筆支援。
  ;;
  ;; 本ファイルの責務:
  ;; - 既存のインラインタグを補完候補にして Org のタグを設定する
  ;;   （`ac1965/org-hugo-set-tags'）
  ;; - `my:f:capture-blog-file' を直接開く（`ac1965/open-capture-blog-file'）
  ;; - Blog capture の確定前にタグを設定する。C-g ではタグ設定だけをスキップする
  ;; - orgx-hugo.el の "b" テンプレートから EXPORT_HUGO_TAGS のプロンプトを除く
  ;;   （`orgx-hugo-capture-prompt-tags-p' を nil にする）
  ;;
  ;; 関数名は ac1965.el のリーダーキー割り当てが参照するため、旧来の接頭辞のまま。
  ;;; Code:

  ;; バイトコンパイル時の警告を避けるための宣言（実体は各パッケージ／ライブラリ側にある）。
  (declare-function org-get-tags "org")
  (declare-function org-map-entries "org")
  (declare-function org-set-tags-command "org")

  ;; ---------------------------------------------------------------------------
  ;; all-posts.org（Hugo ブログ）の既存タグ補完付きタグ設定
  ;; ---------------------------------------------------------------------------
  ;;
  ;; my:f:capture-blog-file（personal/ac1965.el で all-posts.org に上書き済み）を
  ;; 走査し、過去に使ったインラインタグを補完候補にした状態で
  ;; org-set-tags-command を呼ぶ。
  ;;
  ;; キャプチャ用の *Capture* バッファ自体には他の見出しが無いため、
  ;; 補完対象はカレントバッファではなく my:f:capture-blog-file を直接開いて集める。
  ;;

  (defun ac1965--org-hugo-tag-alist-from-buffer ()
    "Return existing inline tags from `my:f:capture-blog-file'.

  The tags are returned in `org-tag-alist' format.
  Return nil when the file is unset or does not exist."
    (let (tags)
      (when (and (bound-and-true-p my:f:capture-blog-file)
                 (file-exists-p my:f:capture-blog-file))
        (with-current-buffer (find-file-noselect my:f:capture-blog-file)
          (org-map-entries
           (lambda ()
             (dolist (tag (org-get-tags nil t))
               (unless (member tag tags)
                 (push tag tags)))))))
      (mapcar #'list tags)))

  ;; 特殊変数であることをコンパイラへ伝える（Org を読み込まずにコンパイルされても、
  ;; 下の let が動的束縛として扱われるようにするため）。宣言が無いと、この let は字句的束縛になり、タグ候補の指定が効かない。
  (defvar org-tag-alist)

  (defun ac1965/org-hugo-set-tags ()
    "Set Org tags on the current heading using existing Hugo tags as candidates.

  This is the normal interactive tag-setting command.  Special handling
  of `C-g' during Blog capture is implemented by
  `ac1965--org-capture-set-blog-tags', not here.
  Signal a `user-error' outside `org-mode' buffers, where the Org parser
  would otherwise warn and fail."
    (interactive)
    (unless (derived-mode-p 'org-mode)
      (user-error "Org バッファではありません: %s" (buffer-name)))
    (let ((org-tag-alist (ac1965--org-hugo-tag-alist-from-buffer)))
      (call-interactively #'org-set-tags-command)))


  ;; ---------------------------------------------------------------------------
  ;; all-posts.org（Hugo ブログ）を直接開くショートカット
  ;; ---------------------------------------------------------------------------

  ;;
  ;; ブログ記事の一覧・既存タグの確認・手動編集のために、
  ;; キャプチャを経由せず my:f:capture-blog-file を直接開きたい場面向け。
  ;;
  ;; 個人設定の上書きが未反映（orgx-core.el の既定値 blog.org のまま）だったり、
  ;; パス自体が存在しない環境で呼んだ場合は find-file を黙って失敗させず、
  ;; user-error で理由を示す。
  ;;

  (defun ac1965/open-capture-blog-file ()
    "Open `my:f:capture-blog-file', the single-file ox-hugo blog source."
    (interactive)
    (if (and (bound-and-true-p my:f:capture-blog-file)
             (file-exists-p my:f:capture-blog-file))
        (find-file my:f:capture-blog-file)
      (user-error
       "my:f:capture-blog-file が未設定か、ファイルが存在しません: %s"
       (bound-and-true-p my:f:capture-blog-file))))


  ;; ---------------------------------------------------------------------------
  ;; Blog capture の before-finalize でタグを設定する
  ;; ---------------------------------------------------------------------------
  ;;
  ;; 目的:
  ;;
  ;;   C-g → タグだけキャンセル → capture → ox-hugo
  ;;
  ;; capture の確定フロー:
  ;;
  ;;   C-c C-c
  ;;       ↓
  ;;   org-capture-before-finalize-hook
  ;;       ↓
  ;;   ac1965--org-capture-set-blog-tags
  ;;       ↓
  ;;   ac1965/org-hugo-set-tags
  ;;       │
  ;;       ├─ タグ設定完了
  ;;       │      ↓
  ;;       │   正常 return
  ;;       │
  ;;       └─ C-g
  ;;            ↓
  ;;          quit
  ;;            ↓
  ;;          condition-case で捕捉
  ;;            ↓
  ;;          タグ設定をスキップ
  ;;            ↓
  ;;          正常 return
  ;;       ↓
  ;;   org-capture finalize
  ;;       ↓
  ;;   org-capture-after-finalize-hook
  ;;       ↓
  ;;   orgx-auto-hugo / ox-hugo
  ;;
  ;; 重要:
  ;;
  ;; `condition-case' の範囲は `ac1965/org-hugo-set-tags' の呼び出しだけ。
  ;;
  ;; したがってタグ選択中の C-g は `org-capture-finalize' まで伝播せず、
  ;; タグ設定だけをキャンセルする。
  ;;
  ;; `quit' を捕捉した後も、この hook 関数は正常 return するため、
  ;; `org-capture-before-finalize-hook' は正常終了し、capture の finalize と
  ;; その後の ox-hugo 処理が継続する。
  ;;
  ;; なお、通常の capture 自体をキャンセルする `C-c C-k' には介入しない。
  ;;

                    (&optional prop-name local))
  (declare-function orgx-auto-hugo-blog-capture-p "orgx-auto-hugo")

  (defun ac1965--org-capture-set-blog-tags ()
    "Set tags for a Blog capture before finalization.
  A capture is a Blog capture when it targets `my:f:capture-blog-file'
  (see `orgx-auto-hugo-blog-capture-p').

  When `C-g' is pressed during tag selection, catch the resulting
  `quit' locally and skip only the tag-setting operation.

  The function then returns normally, allowing `org-capture-finalize'
  and subsequent ox-hugo processing to continue."

               (orgx-auto-hugo-blog-capture-p))
      (condition-case nil
          (ac1965/org-hugo-set-tags)
        (quit
         (message "タグ設定をスキップしました")))))

  (add-hook 'org-capture-before-finalize-hook
            #'ac1965--org-capture-set-blog-tags)


  ;; ---------------------------------------------------------------------------
  ;; Blog capture template
  ;; ---------------------------------------------------------------------------
  ;;
  ;; タグは `ac1965--org-capture-set-blog-tags' が `org-capture-before-finalize-hook' で
  ;; 設定する。capture template 側で `%^{Tags}' を使うとタグ入力が二重になるため、
  ;; テンプレートからタグのプロンプトを除く。
  ;;
  ;; テンプレート本体は orgx-hugo.el が持つ。ここで "b" テンプレートを丸ごと置き換えると
  ;; 本文が二重になるため、オプションで切り替える形にしている。personal は modules.el より前にロードされるので、
  ;; `orgx-hugo' の defcustom より先に値が入る。defcustom は既存の値を上書きしない。
  ;;
  (setopt orgx-hugo-capture-prompt-tags-p nil)

  (provide 'personal-hugo)

  (defgroup personal-messages nil
    "macOS Messages.app archiver."
    :group 'convenience)

  (defcustom personal-messages-db-path
    (expand-file-name "~/Library/Messages/chat.db")
    "Path to the Messages.app SQLite database."
    :type 'file :group 'personal-messages)

  (defcustom personal-messages-archive-dir
    (expand-file-name "messages/"
                      (or (bound-and-true-p my:d:org-roam)
                          (expand-file-name "org-roam/" (or (bound-and-true-p my:d:org)
                                                            (expand-file-name "~/org")))))
    "Directory where archived message notes are saved."
    :type 'directory :group 'personal-messages)

  (defcustom personal-messages-last-archived nil
    "Timestamp of the last archived message."
    :type '(choice (const nil) float) :group 'personal-messages)

  (defun personal-messages--db-available-p ()
    (and (eq system-type 'darwin)
         (file-readable-p personal-messages-db-path)
         (executable-find "sqlite3")))

  (defun personal-messages--query ()
    (when (personal-messages--db-available-p)
      (let* (;; last-archived は Unix 秒。chat.db の message.date は 2001-01-01 起点の
             ;; ナノ秒なので、978307200（2001-01-01 の Unix 時刻）を引いてから換算する。
             (since (or personal-messages-last-archived 0))
             (cmd (format
                   "sqlite3 -readonly %s \"SELECT handle.id, message.text, message.date FROM message JOIN handle ON message.handle_id = handle.rowid WHERE message.date > %d AND message.is_from_me = 0 ORDER BY message.date DESC LIMIT 50;\""
                   (shell-quote-argument personal-messages-db-path)
                   (round (* (max 0 (- since 978307200)) 1e9)))))
        (let ((output (shell-command-to-string cmd)))
          (when (and output (not (string-empty-p (string-trim output))))
            (split-string output "\n" t))))))

  (defun personal-messages--archive-message (contact text timestamp)
    (let* ((date-str (format-time-string "%Y-%m-%d" (seconds-to-time timestamp)))
           (slug (replace-regexp-in-string "[^[:alnum:]]+" "-"
                                           (downcase (or contact "unknown"))))
           (filename (format "%s-messages-%s.org" date-str slug))
           (path (expand-file-name filename personal-messages-archive-dir)))
      (unless (file-directory-p personal-messages-archive-dir)
        (make-directory personal-messages-archive-dir t))
      (with-temp-buffer
        (when (file-exists-p path)
          (insert-file-contents path))
        (goto-char (point-max))
        (unless (looking-back "\n" 1)
          (insert "\n"))
        (insert (format "\n* [%s] %s\n%s\n"
                        (format-time-string "%Y-%m-%d %H:%M" (seconds-to-time timestamp))
                        (or contact "Unknown")
                        (or text "")))
        (write-region (point-min) (point-max) path nil 'silent))))

  ;;;###autoload
  (defun personal-messages-archive ()
    "Archive new messages from Messages.app into org-roam."
    (when (personal-messages--db-available-p)
      (condition-case err
          (let ((rows (personal-messages--query))
                (count 0))
            (dolist (row rows)
              (let* ((parts (split-string row "|"))
  		   (contact (nth 0 parts))
  		   (text    (nth 1 parts))
  		   (ts-ns   (string-to-number (or (nth 2 parts) "0")))
  		   (ts-mac  (/ ts-ns 1e9))
  		   (ts      (+ ts-mac 978307200)))
                (when (> ts 0)
                  (personal-messages--archive-message contact text ts)
                  (cl-incf count)
                  (when (> ts (or personal-messages-last-archived 0))
                    ;; personal-messages-last-archived はセッションをまたいで
                    ;; 永続化する必要がある defcustom である。setopt は値を設定するだけだが、
                    ;; customize-save-variable は設定と同時に custom-file へ書き出すため、
                    ;; Emacs を再起動しても値が保たれる。
                    (customize-save-variable
                     'personal-messages-last-archived ts)))))
            (when (> count 0)
              (message "[personal-messages] archived %d message(s)" count)))
        (error
         (message "[personal-messages] archive failed: %s"
                  (error-message-string err))))))

  (provide 'personal-messages)

  (defun org-babel-execute:claude (body params)
    "Execute a Claude Babel block with BODY as the user message.
  PARAMS is the alist of header arguments from the source block.
  Returns the assistant response text as a string, suitable for
  insertion as the block result under :results value semantics."
    (let* ((system  (or (cdr (assq :system params))
                        personal-ai-default-system))
           (model   (cdr (assq :model params)))
           (tokens  (when-let* ((raw (cdr (assq :tokens params))))
                      (if (stringp raw) (string-to-number raw) raw)))
           (messages (list (list :role "user" :content body))))
      (condition-case err
          (utils-claude-request-sync messages model tokens system)
        (utils-claude-error
         (error "Claude Babel block failed: %s" (cadr err))))))

  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao

  ;;
  ;; Category: personal
  ;;
  ;;; Commentary:
  ;;
  ;; =~/.local/bin/localllm= （ローカル Ollama モデルへのルーター）を Emacs から呼び出すための
  ;; 薄い統合層。プロンプトの内容に応じてどのモデル（qwen3:14b / qwen3-coder /
  ;; LFM2.5-8B-A1B / qwen2.5vl）へ振り分けるかの判定ロジックは、すべて
  ;; =~/.local/bin/localllm= 側の責務であり、本ファイルはそれに一切関与しない。
  ;; 本ファイルの責務は次の3点のみ:
  ;;
  ;;   1. プロンプトをルータープロセスの標準入力へ送る
  ;;   2. 応答をストリーミングで `personal-llm-output-buffer' へ挿入する
  ;;   3. Org-roam / コーディングバッファ向けの薄いラッパーコマンドを提供する
  ;;
  ;; 公開 API:
  ;;   `my/llm-run'                    — 任意のプロンプトをルーターへ送る（対話コマンド）
  ;;   `my/llm-run-from-org-roam'      — 現在の Org-roam ノート（リージョンか全体）を送る。
  ;;                                     タスクは指定しない — ノートは雑多な内容を含み得るため
  ;;                                     ルーター側のルールベース自動判定に委ねる。
  ;;   `my/llm-run-from-coding-buffer' — ポイント位置の defun（かリージョン）を
  ;;                                     --task coding 固定で送る。自動判定を待たず
  ;;                                     確実に qwen3-coder へ振り分けるため。
  ;;
  ;; 実行ファイルの場所は `personal-llm-script-path' で変更できる。
  ;; 本モジュールは org を要求しない（Org の遅延ロード方針を壊さない）。
  ;;
  ;; スクリプト名を単に "llm" にしなかったのは、Homebrew の llm（datasette 版、
  ;; 既定で OpenAI API を叩く）と PATH 上で衝突するため。本モジュールは
  ;; `expand-file-name' で解決した絶対パスを直接 `make-process' に渡すので
  ;; その衝突の影響を受けないが、同じ理由でユーザーがターミナルから素の
  ;; "llm" と打つと Homebrew 版に奪われる（実際に発生し、OpenAI の課金エラーが
  ;; 出た）。以後は "localllm" という別名を使うことでこれを避けている。
  ;;
  ;;; Code:

    (require 'cl-lib)
    (require 'subr-x))

  (defgroup personal-llm nil
    "Local Ollama model router integration (~/.local/bin/localllm)."
    :group 'tools
    :prefix "personal-llm-")

  (defcustom personal-llm-script-path "~/.local/bin/localllm"
    "Path to the local LLM router script invoked by `my/llm-run'."
    :type 'file
    :group 'personal-llm)

  (defcustom personal-llm-output-buffer "*LLM Router Output*"
    "Name of the buffer used to display streamed LLM router output."
    :type 'string
    :group 'personal-llm)

  (defconst personal-llm--valid-tasks '(general coding agent vision)
    "Task symbols accepted by the ~/.local/bin/localllm router's --task flag.")

  ;;; ── 非公開ヘルパー ────────────────────────────────────────────────────────

  (defun personal-llm--ensure-script ()
    "Return the expanded, executable path to the router script.
  Signals `user-error' if `personal-llm-script-path' does not point to an
  executable file."
    (let ((script (expand-file-name personal-llm-script-path)))
      (unless (file-executable-p script)
        (user-error "LLM router script not found or not executable: %s" script))
      script))

  (defun personal-llm--task-string (task)
    "Return TASK (a symbol) as the string expected by the router's --task flag.
  Signals `user-error' if TASK is not one of `personal-llm--valid-tasks'."
    (unless (memq task personal-llm--valid-tasks)
      (user-error "Unknown LLM task %S (expected one of %S)"
                  task personal-llm--valid-tasks))
    (symbol-name task))

  (defun personal-llm--defun-at-point ()
    "Return the top-level defun source string surrounding point, or nil."
    (save-excursion
      (condition-case nil
          (progn
            (beginning-of-defun)
            (let ((beg (point)))
              (end-of-defun)
              (buffer-substring-no-properties beg (point))))
        (error nil))))

  (defun personal-llm--sentinel (proc event)
    "Report completion of the router PROC via EVENT in the echo area."
    (when (memq (process-status proc) '(exit signal))
      (message "[llm] %s" (string-trim event))))

  (defun personal-llm--prepare-output-buffer (task)
    "Pop to `personal-llm-output-buffer', appending a heading for TASK.
  TASK is a symbol or nil (rendered as \"auto\" in the heading).
  Returns the buffer, with point at its end."
    (let ((buf (get-buffer-create personal-llm-output-buffer)))
      (with-current-buffer buf
        (unless (derived-mode-p 'org-mode)
          (org-mode))
        (goto-char (point-max))
        (unless (bobp)
          (insert "\n\n"))
        (insert (format "* llm (%s) — %s\n\n"
                        (or task "auto")
                        (format-time-string "%Y-%m-%d %H:%M:%S")))
        (goto-char (point-max)))
      (pop-to-buffer buf)
      buf))

  (defun personal-llm--start-process (prompt task image-path)
    "Start the router process for PROMPT, streaming into its output buffer.
  TASK, when non-nil, is validated and forwarded as the router's --task flag.
  IMAGE-PATH, when non-nil, is expanded and forwarded as --image."
    (let* ((script (personal-llm--ensure-script))
           (task-str (and task (personal-llm--task-string task)))
           (command (append (list script)
                            (when task-str (list "--task" task-str))
                            (when image-path
                              (list "--image" (expand-file-name image-path)))))
           (buf (personal-llm--prepare-output-buffer task))
           (proc (make-process :name "personal-llm"
                               :buffer buf
                               :command command
                               :noquery t
                               :sentinel #'personal-llm--sentinel)))
      (process-send-string proc prompt)
      (process-send-eof proc)
      proc))

  ;;; ── 対話コマンド ──────────────────────────────────────────────────────────

  (defun my/llm-run (prompt &optional task image-path)
    "Send PROMPT to the local LLM router and stream the response.
  TASK, when non-nil, must be one of the symbols `general', `coding',
  `agent', or `vision'; it is forwarded as the router's --task flag,
  overriding its own rule-based auto-detection. When TASK is nil, the
  router decides from PROMPT's content (or from IMAGE-PATH's presence).
  IMAGE-PATH, when non-nil, is forwarded as the router's --image flag.

  Interactively, PROMPT is the active region if any, otherwise it is
  read from the minibuffer; TASK and IMAGE-PATH are left nil. Call this
  function from Lisp (see `my/llm-run-from-coding-buffer') to pin a task
  or attach an image."
    (interactive
     (list (if (use-region-p)
               (buffer-substring-no-properties (region-beginning) (region-end))
             (read-string "LLM prompt: "))))
    (when (string-empty-p (string-trim prompt))
      (user-error "Nothing to send to the LLM router"))
    (message "[llm] sending to router (task: %s)..." (or task "auto"))
    (personal-llm--start-process prompt task image-path))

  (defun my/llm-run-from-org-roam ()
    "Send the current Org-roam note to the LLM router.
  Sends the active region if any, otherwise the whole buffer. The task
  is left unspecified so the router's rule-based detection picks it —
  Org-roam notes span general writing, coding notes, and action items
  alike, so pinning a single task here would waste that detection."
    (interactive)
    (my/llm-run
     (if (use-region-p)
         (buffer-substring-no-properties (region-beginning) (region-end))
       (buffer-substring-no-properties (point-min) (point-max)))))

  (defun my/llm-run-from-coding-buffer ()
    "Send the current defun (or active region) to the LLM router as `coding'.
  Pinning the task bypasses the router's rule-based auto-detection so the
  prompt is always routed to the coding model, regardless of how much
  prose the snippet happens to mix in."
    (interactive)
    (let ((src (if (use-region-p)
                   (buffer-substring-no-properties (region-beginning) (region-end))
                 (personal-llm--defun-at-point))))
      (unless src
        (user-error "No region active and no defun found at point"))
      (my/llm-run src 'coding)))

  (provide 'personal-llm)

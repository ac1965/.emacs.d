vcs 層（バージョン管理）のモジュールの正本です。
tangle 先は =README.org= と同じ =.emacs.d/= からの相対パス（ =../= 付き）です。
全体の設計と索引は =../README.org= にあります。説明とコードは、各節の中に同居させています。

* vcs/
:PROPERTIES:
:CUSTOM_ID: vcs-modules
:END:

vcs 層は、Git を中心とするバージョン管理の層です。 =early-init → core → ui → auth → completion → orgx → vcs → dev → utils → personal= の
並びで、orgx の次、dev の前にあります。上位の層（dev、utils、personal）には依存できません。

*構成*

| モジュール | 責務 |
|------------|------|
| =vcs-core= | 組み込みの =vc= の設定、競合解決（ =smerge= ）、 =M-SPC g= 以下のキー割り当て |
| =vcs-magit= | Magit の設定、コミットメッセージの補助、ワークツリーの管理、Ediff の配置 |
| =vcs-gutter= | diff-hl による、変更箇所のガター表示 |
| =vcs-forge= | Forge（Issue と Pull Request）と、 =gh= を使った GitHub の認証 |

ロード順は =lisp/modules.el= の =my:modules= の並びどおりで、上の表の順です。 =vcs-core= が先に、
ほかの 3 つが使う関数の宣言（ =declare-function= ）とキーの割り当てを用意します。

*この層の方針*

- *起動を遅くしない* — Magit と diff-hl は、起動時にロードしません。Magit の全体キーは autoload のコマンドで
  割り当て、diff-hl はアイドル時に有効にします。ロードに掛かる時間（Magit の全体キーの割り当てで 50〜95 ms、
  diff-hl で約 80 ms）を、使える状態になるまでの道筋から外すためです。
- *組み込みと Magit を両立させる* — Emacs 31 の =vc= で足りる操作は組み込みで使えるようにし、Magit も残します。
  どちらを使い続けるかは、使ってみた実感で決めるためです。
- *キーは 1 か所の leader に集める* — Git の操作は、 =M-SPC g= の下にまとまっています。 =s c d l b= は
  =ui-keys.el= 側、残りは =vcs-core= が、 =after-init-hook= の depth 90 で割り当てます。

*キーの一覧*

| キー（ =M-SPC g= の次） | コマンド | 割り当てるモジュール |
|--------------------------+----------+----------------------|
| =s= / =c= / =d= / =l= / =b= | status / commit / diff / log / blame | =ui-keys.el= |
| =f= / =F= / =P= / =B= / =z= | fetch / pull / push / branch / stash | =vcs-core= |
| =h= | ファイルの履歴（ =magit-log-buffer-file= ） | =vcs-core= |
| =]= / =[= / =H= | 次 / 前の hunk、hunk を表示（ diff-hl ） | =vcs-core= |
| =i= / =r= / =N= | Issue 一覧、Pull Request 一覧、 =forge-dispatch= | =vcs-core= |
| =w= / =W= / =X= | ワークツリーへ切り替え、追加、削除 | =vcs-core= （ =vcs-magit= のコマンド） |
| =m= | 競合の解決（ =n= / =p= / =u= / =l= / =b= / =a= / =e= / =r= ） | =vcs-core= |


* vcs/vcs-core.el
:PROPERTIES:
:CUSTOM_ID: vcs-core
:header-args:emacs-lisp: :tangle ../lisp/vcs/vcs-core.el
:END:

Emacs 31 は =vc= の大部分を書き直しました（NEWS のエントリだけで 40 件を超えます）。

これまで「Magit を使う理由」になっていた操作の多くが、いまや組み込みのインタフェースから
使えます。複数ワークツリー、cherry-pick と revert、incoming/outgoing の差分、非同期チェック
イン、VC Directory からの stash 削除 — このあたりです。

*それでも Magit は消していません*

本モジュールは Magit を *削除しません* 。組み込み層を有効化して、両方を使える状態にしています。

理由は単純で、「Magit をやめられるかどうか」は、思い込みではなく実際に使ってみた実感で判断
すべきだからです。まず両方を使える状態を作り、それから決める。その順序を守るための構成です。
やめるか否かの判断を、思い込みではなく実測した経験に基づいて下せるようにするためです。

*このモジュールが設定するもの*

- *組み込みの* =vc= — Emacs 31 以上でだけ有効です（ =:if (>= emacs-major-version 31)= ）。
  - =vc-allow-rewriting-published-history= は =nil= です。公開済みの履歴を書き換える操作を断ります。
    Emacs 31 の書き直しで加わった、いちばん価値のある安全装置です。
  - =vc-async-checkin= と =vc-display-failed-async-commands= は =t= です。チェックインを非同期で行い、
    失敗は握りつぶさずに表に出します。
  - =vc-use-incoming-outgoing-prefixes= は =t= です。incoming / outgoing 系のコマンドを、専用の接頭辞で区別します。
  - =vc-dir-auto-hide-up-to-date= と =vc-dir-save-some-buffers-on-revert= は =t= です。VC Directory から、
    変更のないファイルを隠し、更新の前に未保存のバッファを保存するか尋ねます。
  - =vc-resolve-conflicts= は =t= です。マージで競合が残ると、競合の解決（ =smerge= ）を出します。
  - =log-edit-hook= は =log-edit-show-files= と =log-edit-show-diff= です。コミットの前に、対象のファイルと差分を並べます。
  - =vc-auto-revert-mode= があれば有効にします。Emacs の外でブランチを切り替えたり、rebase や pull をしても、
    開いているバッファが読み直されます。
- *競合の解決* （ =smerge= ） — ファイルを開いたとき、 =<<<<<<<= で始まる行があれば =smerge-mode= を有効にします
  （ =vcs-core--maybe-enable-smerge= ）。競合のないバッファから =M-SPC g m= を押しても未定義にならないよう、
  コマンドは =:commands= で autoload にしてあります。
- *競合解決のキーマップ* — =vcs-core-smerge-map= は =:repeat t= です。 =M-SPC g m= を最初に 1 回押すと、
  =repeat-mode= が有効なときは、続く =n= （次）、 =p= （前）、 =u= （上を採用）、 =l= （下を採用）、
  =b= （ベースを採用）、 =a= （両方を採用）、 =e= （ ediff ）、 =r= （細分）を、接頭辞なしで続けて押せます。
- *キー割り当て* — =vcs-core--bind-keys= が、上の表のキーを =ui-leader-g-map= へ割り当てます。
  =after-init-hook= の depth 90 に登録するのは、leader のマップを作る =ui-keymap= の処理（depth 0）より
  後に走らせる必要があるためです。コマンドは、Magit や diff-hl、Forge の autoload です。まだロードしていなくても、
  キーを押した時点でロードされます。

*注意*

- Emacs 31 未満では、 =vc= の設定が丸ごと無効になります。キーと =smerge= の設定は、バージョンに関係なく有効です。
- =defun= は =leaf= より前に置いています。 =:hook= に関数名を書くと、 =leaf= がその関数が未定義のとき
  autoload と =declare-function= を出すため、後ろに置くと「defined multiple times」の警告になります。
- この層は dev 層に依存してはいけません。 =declare-function= はバイトコンパイルの警告を避けるための宣言で、
  実体の関数は、各パッケージが autoload で用意します。

#+begin_src emacs-lisp
  ;;; vcs/vcs-core.el --- 組み込み VC のポリシー（Emacs 31） -*- lexical-binding: t; -*-
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: vcs
  ;;
  ;;; Commentary:
  ;;
  ;; Emacs 31 の VC 書き直しを活用した、組み込み `vc' の設定。
  ;;
  ;; 覚えておく価値のあるキーバインド（すべて組み込み。サードパーティ不要）:
  ;;
  ;;   C-x v v     vc-next-action            C-x v @   vc-revert
  ;;   C-x v b l   vc-print-fileset-branch-log
  ;;   C-x v b L   vc-print-root-branch-log
  ;;   C-x v R     vc-rename-file            C-x v !   （独自の入力履歴）
  ;;   VC Directory 内:  V  vc-dir-root-next-action
  ;;                     z d / D  Git の stash を削除
  ;;
  ;; leader（M-SPC g）の git キー割り当て:
  ;;
  ;;   s status   c commit   d diff   l log   b blame      （ui-keys.el 側の既存の割り当て）
  ;;   f fetch    F pull     P push   B branch  z stash    （本モジュール）
  ;;   h ファイルの履歴（magit-log-buffer-file）
  ;;   ] / [ 次 / 前の hunk   H hunk を表示                  （diff-hl）
  ;;   i Issue 一覧   r Pull Request 一覧   N forge-dispatch  （forge）
  ;;   m 競合の解決（n 次 p 前 u 上 l 下 b ベース a 両方 e ediff r 細分）
  ;;   w ワークツリーへ切り替え   W ワークツリーを追加   X ワークツリーを削除   （vcs-magit.el）
  ;;
  ;; 本ファイルの責務に、上のキー割り当てと、競合解決のキーマップ `vcs-core-smerge-map' が
  ;; 含まれる。キーは `after-init-hook'（depth 90）で割り当てる。leader のマップは
  ;; ui-keymap の `after-init-hook'（depth 0）で作られるため、その後に走らせる必要がある。
  ;;
  ;; 本モジュールは dev 層に依存してはならない（層の不変条件）。
  ;;; Code:

  (eval-when-compile (require 'leaf))

  ;; バイトコンパイル時の警告を避けるための宣言（実体は各パッケージ側にある）。
  (defvar ui-leader-g-map)
  (declare-function magit-fetch "magit-fetch")
  (declare-function magit-pull "magit-pull")
  (declare-function magit-push "magit-push")
  (declare-function magit-branch "magit-branch")
  (declare-function magit-stash "magit-stash")
  (declare-function magit-log-buffer-file "magit-log")
  (declare-function diff-hl-next-hunk "diff-hl")
  (declare-function diff-hl-previous-hunk "diff-hl")
  (declare-function diff-hl-show-hunk "diff-hl-show-hunk")
  (declare-function forge-list-issues "forge-list")
  (declare-function forge-list-pullreqs "forge-list")
  (declare-function forge-dispatch "forge-commands")
  (declare-function vcs-magit-worktree-add "vcs-magit")
  (declare-function vcs-magit-worktree-switch "vcs-magit")
  (declare-function vcs-magit-worktree-remove "vcs-magit")
  (declare-function smerge-next "smerge-mode")
  (declare-function smerge-prev "smerge-mode")
  (declare-function smerge-keep-upper "smerge-mode")
  (declare-function smerge-keep-lower "smerge-mode")
  (declare-function smerge-keep-base "smerge-mode")
  (declare-function smerge-keep-all "smerge-mode")
  (declare-function smerge-refine "smerge-mode")

  (leaf vc
    :straight nil
    :if (>= emacs-major-version 31)
    :custom
    (;; Refuse to rewrite history that has already been published.  This is the
     ;; Emacs 31 の VC 書き直しで追加された、最も価値のある安全オプション。
     (vc-allow-rewriting-published-history . nil)
     ;; チェックインは非同期で行う。失敗は握りつぶさず表面化させる。
     (vc-async-checkin                 . t)
     (vc-display-failed-async-commands . t)
     ;; incoming/outgoing 系のコマンドを独自の接頭辞で区別する。
     (vc-use-incoming-outgoing-prefixes . t)
     ;; VC Directory の整理。
     (vc-dir-auto-hide-up-to-date        . t)
     (vc-dir-save-some-buffers-on-revert . t)
     ;; マージで衝突が残った場合、衝突解決（smerge）を提示する。
     (vc-resolve-conflicts . t)
     ;; コミット前に、log-edit バッファでコミット差分を表示する。
     (log-edit-hook . '(log-edit-show-files log-edit-show-diff)))
    :config
    ;; Emacs 31: 作業ツリーが Emacs の外側で変化した場合（ブランチ切替、rebase、pull）、
    ;; バッファを自動的に再読込する。
    (when (fboundp 'vc-auto-revert-mode)
      (vc-auto-revert-mode 1)))

  (defun vcs-core--maybe-enable-smerge ()
    "Enable `smerge-mode' when the visited file contains conflict markers."
    (save-excursion
      (goto-char (point-min))
      (when (re-search-forward "^<<<<<<< " nil t)
        (smerge-mode 1))))

  ;; SMerge は Emacs 31 で `repeat-map' を獲得した。最初の衝突コマンドの後は、
  ;; 以降のキーを接頭辞なしで繰り返せる。
  ;; defun は leaf より前に置く。:hook に関数名を書くと leaf は、その関数が未定義なら
  ;; パッケージ名への autoload と declare-function を出すため、後ろに置くと
  ;; 「defined multiple times」の警告になり、誤った autoload も一瞬登録される。
  ;; :commands は、競合のないバッファから M-SPC g m を押しても未定義にならないための autoload。
  (leaf smerge-mode
    :straight nil
    :commands (smerge-next smerge-prev smerge-keep-upper smerge-keep-lower
               smerge-keep-base smerge-keep-all smerge-ediff smerge-refine)
    :hook ((find-file-hook . vcs-core--maybe-enable-smerge)))

  ;; 競合の解決。最初の 1 回だけ M-SPC g m を押せば、あとは接頭辞なしで n / p / u / l を
  ;; 続けて押せる（`:repeat t' により、`repeat-mode' が有効なときに繰り返しになる）。
  (defvar-keymap vcs-core-smerge-map
    :doc "Conflict resolution keys under M-SPC g m."
    :repeat t
    "n" #'smerge-next
    "p" #'smerge-prev
    "u" #'smerge-keep-upper
    "l" #'smerge-keep-lower
    "b" #'smerge-keep-base
    "a" #'smerge-keep-all
    "e" #'smerge-ediff
    "r" #'smerge-refine)

  (defun vcs-core--bind-keys ()
    "Bind the git commands that ui-keys.el does not know about under M-SPC g."
    (when (and (boundp 'ui-leader-g-map) (keymapp ui-leader-g-map))
      (keymap-set ui-leader-g-map "f" #'magit-fetch)
      (keymap-set ui-leader-g-map "F" #'magit-pull)
      (keymap-set ui-leader-g-map "P" #'magit-push)
      (keymap-set ui-leader-g-map "B" #'magit-branch)
      (keymap-set ui-leader-g-map "z" #'magit-stash)
      (keymap-set ui-leader-g-map "h" #'magit-log-buffer-file)
      (keymap-set ui-leader-g-map "]" #'diff-hl-next-hunk)
      (keymap-set ui-leader-g-map "[" #'diff-hl-previous-hunk)
      (keymap-set ui-leader-g-map "H" #'diff-hl-show-hunk)
      (keymap-set ui-leader-g-map "i" #'forge-list-issues)
      (keymap-set ui-leader-g-map "r" #'forge-list-pullreqs)
      (keymap-set ui-leader-g-map "N" #'forge-dispatch)
      (keymap-set ui-leader-g-map "w" #'vcs-magit-worktree-switch)
      (keymap-set ui-leader-g-map "W" #'vcs-magit-worktree-add)
      (keymap-set ui-leader-g-map "X" #'vcs-magit-worktree-remove)
      (keymap-set ui-leader-g-map "m" vcs-core-smerge-map)))

  ;; depth 90: ui-keymap--startup-init（depth 0）がマップを作った後に走らせる。
  (add-hook 'after-init-hook #'vcs-core--bind-keys 90)

  (provide 'vcs-core)
  ;;; vcs/vcs-core.el ends here
#+end_src

* vcs/vcs-magit.el
:PROPERTIES:
:CUSTOM_ID: vcs-magit
:header-args:emacs-lisp: :tangle ../lisp/vcs/vcs-magit.el
:END:

Magit の設定と、Magit の上に載せた 2 つの補助（コミットメッセージとワークツリー）をまとめたモジュールです。

*Magit の見え方*

- ステータスは、フレーム全体に表示します（ =magit-display-buffer-fullframe-status-v1= ）。
  Magit のバッファを閉じる（bury する）と、開く前のウィンドウ構成に戻ります（ =magit-restore-window-configuration= ）。
- 変更された hunk の中で、変わった単語を強調します（ =magit-diff-refine-hunk= ）。行全体の差分より、
  何が変わったかが読みやすくなります。
- コミットメッセージの 1 行目の目安は 72 桁です（ =git-commit-summary-max-length= ）。
- Ediff の制御パネルは、別のフレームにせず、同じフレームで開きます。nano-modeline や posframe を使う環境で、
  フレームの管理を増やさないためです。

*起動を遅くしない工夫*

Magit は、自分の autoload が =after-init-hook= に =magit-maybe-define-global-key-bindings= を登録します。
この関数は、全体キーを割り当てるかどうかを調べるために Magit 本体をロードし、起動に 50〜95 ms 掛かっていました。
そこで、この登録を外し、同じ 3 つの全体キーを autoload のコマンドで割り当てています
（ =magit-define-global-key-bindings= が =default= のときと同じ）。

| キー | コマンド |
|------|----------|
| =C-x g= | =magit-status= |
| =C-x M-g= | =magit-dispatch= |
| =C-c M-g= | =magit-file-dispatch= |

*コミットメッセージの補助*

コミットの件名を =type(scope): 要約= の形にそろえるための、補完と確認です。

- *補完* — コミットメッセージの 1 行目で、まず =type= を補完し（ =feat= 、 =fix= 、 =docs= など）、
  =type(= の後では =scope= を補完します（ =vcs-magit--commit-capf= ）。 =scope= の候補は、そのリポジトリの
  直近 200 件のコミットの件名から集めます。この補完は、そのバッファの先頭に置きます（depth -50、バッファローカル）。
- *確認* — 件名が次のどれにも合わないまま確定しようとすると、 =y-or-n-p= で尋ねます（ =vcs-magit--commit-check= ）。
  - =type(scope): 要約= 、 =type: 要約= 、 =type(scope)!: 要約= （ =type= は英小文字）
  - =Merge= または =Revert= で始まる件名
  - =fixup!= 、 =squash!= 、 =amend!= で始まる件名
- *カスタマイズ* — =vcs-magit-commit-types= で候補の =type= を変えられます。 =vcs-magit-commit-check= を
  =nil= にすると、確認をやめます。

*ワークツリーの管理*

ブランチごとに別の作業ディレクトリを持つための、3 つのコマンドです。キーは =M-SPC g w= / =W= / =X= で、
=vcs-core= が割り当てます。

- =vcs-magit-worktree-add= — ブランチ用のワークツリーを追加します。ブランチがなければ、今の =HEAD= から作ります。
  対話的に呼ぶと、追加したワークツリーで Magit を開きます。
- =vcs-magit-worktree-switch= — リポジトリのワークツリーから選んで、そこで Magit を開きます。
- =vcs-magit-worktree-remove= — ワークツリーを削除します。確認を取り、 =--force= は付けません。
  未コミットの変更があるワークツリーは、git が拒否します。主のワークツリーは、候補に出ません。

追加先は、リポジトリの隣の =<リポジトリ名>.worktrees/<ブランチ名>= です。ブランチ名の =/= は =-= に置き換えます
（ =vcs-magit--worktree-dir= ）。Magit のトランジェント（ =magit-worktree= ）を使わず git を直接呼ぶのは、
トランジェントが毎回ディレクトリを尋ねて、置き場所の規約を持てないためです。

*注意*

- ワークツリーの操作は =process-lines= で git を呼ぶので、git が失敗する（リポジトリの外、同名のブランチ
  がすでにワークツリーにあるなど）と、エラーになります。
- コミットメッセージの補助は、 =git-commit-setup-hook= と =git-commit-finish-query-functions= に登録します。
  Magit のコミット画面だけに効き、 =vc= のコミット（ =C-x v v= ）には効きません。

  ;; Magit（Git クライアント）の設定。
  ;;
  ;; 本ファイルの責務:
  ;; - `magit-display-buffer-fullframe-status-v1' により、ステータスを全画面表示する
  ;;
  ;; - magit バッファを bury するとき、直前のウィンドウ構成を復元する
  ;; - Ediff の制御パネルを別フレームにせず、同一フレームで開く
  ;; - 変更された hunk の中の、変わった単語を強調する（`magit-diff-refine-hunk'）
  ;; - コミットメッセージの 1 行目の目安を 72 桁にする（`git-commit-summary-max-length'）
  ;; - magit が `after-init-hook' に自分で登録する `magit-maybe-define-global-key-bindings' を
  ;;   外し、同じ 3 つの全体キー（C-x g、C-x M-g、C-c M-g）を autoload で自分で割り当てる。
  ;;   この関数は全体キーを割り当てるために magit 本体をロードし、起動に 50〜95 ms かかっていた
  ;; - コミットメッセージの補助: 1 行目で `type(scope): 要約' の type と scope を補完し
  ;;   （`vcs-magit--commit-capf'）、この形でない件名のコミットは、確認してから通す
  ;;   （`vcs-magit--commit-check'）。scope は、直近 200 件のコミットから集める
  ;; - ワークツリー管理: 追加（`vcs-magit-worktree-add'）、切り替え
  ;;   （`vcs-magit-worktree-switch'）、削除（`vcs-magit-worktree-remove'）。
  ;;   追加先は `<リポジトリ>.worktrees/<ブランチ>' で、リポジトリの隣に作る
  ;;   （`/' は `-' に置き換える）。キーは `M-SPC g w / W / X'（vcs-core.el で割り当てる）
  ;;
  ;; ワークツリーの操作は git を直接呼ぶ。Magit のトランジェント（`magit-worktree'）は
  ;; ディレクトリを毎回尋ねるため、置き場所の規約を持てないからである。削除は `--force' を
  ;; 付けない。未コミットの変更があるワークツリーは、git が拒否する。
  ;;; Code:

  ;; バイトコンパイル時の警告を避けるための宣言（実体は各パッケージ／ライブラリ側にある）。
  (declare-function ediff-setup-windows-plain "ediff-wind")
  (declare-function magit-display-buffer-fullframe-status-v1 "magit-mode")
  (declare-function magit-restore-window-configuration "magit-mode")
  (declare-function magit-status "magit-status")
  (declare-function magit-dispatch "magit")
  (declare-function magit-file-dispatch "magit")

  (eval-when-compile (require 'leaf))

  (defgroup vcs-magit nil
    "Magit helpers: commit message assist and worktree management."
    :group 'tools)

  (defcustom vcs-magit-commit-types
    '("feat" "fix" "docs" "style" "refactor" "perf" "test" "build" "ci" "chore" "revert")
    "Conventional-commit types offered when completing the subject line."
    :type '(repeat string)
    :group 'vcs-magit)

  (defcustom vcs-magit-commit-check t
    "When non-nil, ask before committing an off-form subject.
  The form is `type(scope): summary'."
    :type 'boolean
    :group 'vcs-magit)

  (defconst vcs-magit--commit-subject-re
    "\\`\\(?:[a-z]+\\(?:([^()\n]+)\\)?!?: .+\\|Merge \\|Revert \\|\\(?:fixup\\|squash\\|amend\\)! \\)"
    "Subjects the commit check accepts without asking.")

  (defun vcs-magit--recent-scopes ()
    "Return the scopes used in the last 200 commit subjects of this repository."
    (ignore-errors
      (let (scopes)
        (dolist (subject (process-lines "git" "log" "-n" "200" "--format=%s"))
          (when (string-match "\\`[a-z]+(\\([^()]+\\))" subject)
            (push (match-string 1 subject) scopes)))
        (delete-dups (nreverse scopes)))))

  (defun vcs-magit--commit-capf ()
    "Complete the conventional-commit type, then the scope, on the first line."
    (when (= (line-number-at-pos) 1)
      (let* ((bol (line-beginning-position))
             (text (buffer-substring-no-properties bol (point))))
        (cond
         ((string-match-p "\\`[a-z]*\\'" text)
          (list bol (point) vcs-magit-commit-types :exclusive 'no))
         ((string-match "\\`[a-z]+(\\([^()]*\\)\\'" text)
          (list (+ bol (match-beginning 1)) (point)
                (vcs-magit--recent-scopes) :exclusive 'no))))))

  (defun vcs-magit--commit-setup ()
    "Put the commit-message completion first in this buffer's CAPFs."
    (add-hook 'completion-at-point-functions #'vcs-magit--commit-capf -50 t))

  (defun vcs-magit--commit-check (&optional _force)
    "Return non-nil to let the commit go ahead; ask when the subject is off-form."
    (or (not vcs-magit-commit-check)
        (let ((subject (save-excursion
                         (goto-char (point-min))
                         (buffer-substring-no-properties
                          (line-beginning-position) (line-end-position)))))
          (or (string-match-p vcs-magit--commit-subject-re subject)
              (y-or-n-p (format "件名が type(scope): 要約 の形ではありません（%s）。このままコミットしますか？ "
                                subject))))))

  (add-hook 'git-commit-setup-hook #'vcs-magit--commit-setup)
  (add-hook 'git-commit-finish-query-functions #'vcs-magit--commit-check)

  (defun vcs-magit--git-lines (&rest args)
    "Run git with ARGS in `default-directory' and return its output lines."
    (apply #'process-lines "git" args))

  (defun vcs-magit-worktree-list ()
    "Return the paths of all worktrees of the current repository, main one first."
    (delq nil
          (mapcar (lambda (line)
                    (when (string-prefix-p "worktree " line)
                      (file-name-as-directory (substring line (length "worktree ")))))
                  (vcs-magit--git-lines "worktree" "list" "--porcelain"))))

  (defun vcs-magit--worktree-dir (branch)
    "Return the directory a new worktree for BRANCH goes into."
    (let* ((main (directory-file-name (car (vcs-magit-worktree-list)))))
      (file-name-as-directory
       (expand-file-name (concat (file-name-nondirectory main) ".worktrees/"
                                 (replace-regexp-in-string "/" "-" branch))
                         (file-name-directory main)))))

  (defun vcs-magit--branches ()
    "Return the local branch names of the current repository."
    (vcs-magit--git-lines "for-each-ref" "--format=%(refname:short)" "refs/heads"))

  ;;;###autoload
  (defun vcs-magit-worktree-add (branch)
    "Add a worktree for BRANCH next to the repository and return its directory.
  BRANCH is created from HEAD when it does not exist yet.  Interactively, open
  Magit in the new worktree."
    (interactive (list (completing-read "ワークツリーのブランチ（新規可）: "
                                        (vcs-magit--branches))))
    (let ((dir (vcs-magit--worktree-dir branch)))
      (make-directory (file-name-directory (directory-file-name dir)) t)
      (if (member branch (vcs-magit--branches))
          (vcs-magit--git-lines "worktree" "add" dir branch)
        (vcs-magit--git-lines "worktree" "add" "-b" branch dir))
      (when (called-interactively-p 'any)
        (magit-status dir))
      dir))

  ;;;###autoload
  (defun vcs-magit-worktree-switch (dir)
    "Open Magit in the worktree DIR, chosen among the repository's worktrees."
    (interactive (list (completing-read "ワークツリー: " (vcs-magit-worktree-list) nil t)))
    (magit-status dir))

  ;;;###autoload
  (defun vcs-magit-worktree-remove (dir)
    "Remove the worktree DIR after confirmation; git refuses a dirty one."
    (interactive (list (completing-read "削除するワークツリー: "
                                        (cdr (vcs-magit-worktree-list)) nil t)))
    (when (or (not (called-interactively-p 'any))
              (y-or-n-p (format "ワークツリー %s を削除しますか？ " dir)))
      (vcs-magit--git-lines "worktree" "remove" dir)
      (message "ワークツリーを削除しました: %s" dir)))

  (leaf magit :straight t
    :custom ((magit-display-buffer-function . #'magit-display-buffer-fullframe-status-v1)
             (magit-bury-buffer-function . #'magit-restore-window-configuration)
             ;; hunk の中で変わった単語を強調する。行全体の差分より、何が変わったかが読みやすい。
             (magit-diff-refine-hunk . t)
             (git-commit-summary-max-length . 72)))

  ;; magit の全体キーの割り当てを、起動時に magit をロードせずに行う。magit は、自分の
  ;; autoload が `after-init-hook' に `magit-maybe-define-global-key-bindings' を登録する。
  ;; この関数は `magit-define-global-key-bindings' を調べるために magit 本体をロードする。
  ;; 登録を外し、既定の 3 つ（`magit-define-global-key-bindings' が `default' のときと同じ）を
  ;; autoload のコマンドで割り当てる。
  (remove-hook 'after-init-hook #'magit-maybe-define-global-key-bindings)
  (keymap-global-set "C-x g" #'magit-status)
  (keymap-global-set "C-x M-g" #'magit-dispatch)
  (keymap-global-set "C-c M-g" #'magit-file-dispatch)

  ;; Ediff: 制御パネルを別フレームにせず同一フレームで開く（nano-modeline /
  ;; posframe 環境でフレーム管理を増やさないため）。
  (leaf ediff
    :straight nil
    :custom ((ediff-window-setup-function . #'ediff-setup-windows-plain)
             (ediff-split-window-function . #'split-window-horizontally)))

  (provide 'vcs-magit)
  ;;; vcs/vcs-magit.el ends here
#+end_src

* vcs/vcs-gutter.el
:PROPERTIES:
:CUSTOM_ID: vcs-gutter
:header-args:emacs-lisp: :tangle ../lisp/vcs/vcs-gutter.el
:END:

diff-hl による、変更箇所のガター（フリンジ）表示です。追加・変更・削除された行が、左端の印で分かります。

*設計のポイント*

- *アイドル時に有効にする* — diff-hl のロードに約 80 ms 掛かるので、起動後の最初の 1 秒のアイドル時に有効にします
  （ =vcs-gutter--enable-later= ）。使える状態になるまでの道筋から、このコストを外すためです。
  =global-diff-hl-mode= は、有効にした時点で開いているバッファにも効きます。
- *未保存の編集も反映する* — =diff-hl-flydiff-mode= を有効にします。保存を待たずに、編集の途中の変更が
  ガターに出ます。
- *Dired と Magit にも* — Dired では、変更のあるファイルを =diff-hl-dired-mode= が示します。Magit の
  更新の前後（ =magit-pre-refresh= / =magit-post-refresh= ）にも、ガターを更新します。

*キー*

hunk の移動と表示は =M-SPC g ]= （次）、 =[= （前）、 =H= （表示）です。割り当ては =vcs-core= で行います。
diff-hl を起動時にロードしなくなったため、ロードの前にこれらのキーを押しても未定義にならないよう、
3 つのコマンドを =:commands= で autoload にしています（smoketest の leader キーの検査で見つかりました）。


#+begin_src emacs-lisp
  ;;; vcs/vcs-gutter.el --- VCS のガター表示 -*- lexical-binding: t; -*-
  ;;
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: vcs
  ;;
  ;;; Commentary:
  ;;
  ;; diff-hl による VCS のガター表示。
  ;;
  ;; 本ファイルの責務:
  ;; - 初期化後に `global-diff-hl-mode' と `diff-hl-flydiff-mode' を有効化する
  ;;   （後者は、保存前の編集もガターに反映する）。diff-hl のロードに約 80 ms かかるため、
  ;;   起動の 1 秒後のアイドル時に有効にする（`vcs-gutter--enable-later'）。グローバルモードは、
  ;;   有効にした時点で開いているバッファにも効く
  ;; - Dired でも変更のあるファイルを示す（`diff-hl-dired-mode'）
  ;; - magit の pre/post-refresh フックでフリンジ表示を更新する
  ;; - hunk の移動と表示は `M-SPC g ] / [ / H' （vcs-core.el で割り当てる）
  ;;; Code:

  (eval-when-compile (require 'leaf))

  (declare-function global-diff-hl-mode "diff-hl")
  (declare-function diff-hl-flydiff-mode "diff-hl-flydiff")

  ;; defun は leaf より前に置く（:hook に関数名を書くと leaf が autoload を出すため）。
  (defun vcs-gutter--enable ()
    "Enable diff-hl everywhere, with fly-diff so unsaved edits show up too."
    (global-diff-hl-mode 1)
    (diff-hl-flydiff-mode 1))

  (defun vcs-gutter--enable-later ()
    "Enable diff-hl once Emacs has been idle for a second after startup.
  Loading diff-hl takes about 80 ms, so it is kept off the path to a usable Emacs."
    (run-with-idle-timer 1 nil #'vcs-gutter--enable))

  ;; :commands は、diff-hl を起動時にロードしなくなったため、ロード前に M-SPC g ] / [ を
  ;; 押しても「commandp」で落ちないための autoload（smoketest のリーダーキー検査で見つかった）。
  (leaf diff-hl
    :straight t
    :commands (diff-hl-next-hunk diff-hl-previous-hunk diff-hl-show-hunk)
    :hook ((after-init-hook . vcs-gutter--enable-later)
           (dired-mode-hook . diff-hl-dired-mode)
           (magit-pre-refresh . diff-hl-magit-pre-refresh)
           (magit-post-refresh . diff-hl-magit-post-refresh)))

  (provide 'vcs-gutter)
  ;;; vcs/vcs-gutter.el ends here
#+end_src

* vcs/vcs-forge.el
:PROPERTIES:
:CUSTOM_ID: vcs-forge
:header-args:emacs-lisp: :tangle ../lisp/vcs/vcs-forge.el
:END:

GitHub / GitLab の Issue と Pull Request を、Magit から扱うための Forge の設定です。Magit が使える状態に
なってから、Forge をロードします（ =:after magit= ）。キーは =M-SPC g i= （Issue 一覧）、 =r= （Pull Request 一覧）、
=N= （ =forge-dispatch= ）で、 =vcs-core= が割り当てます。

*GitHub の認証*

Forge が使う ghub は、トークンを auth-source から「ホスト =api.github.com= 、ユーザー =<github.user>^forge= 」で探します。
通常は、 =~/.authinfo= や pass にトークンを書いて用意しますが、ここでは =gh auth token= が出す、
ログイン済みのトークンを返します。

- トークンを別の場所に複製しないので、 =gh auth login= と =gh auth refresh= だけで更新できます。
- =auth-source-search= に =:around= の advice を付けて実現しています（ =vcs-forge--auth-source-via-gh= ）。
  この advice が答えるのは、ホストが =api.github.com= または =github.com= で、ユーザーが =^forge= か =^ghub= で
  終わる検索だけです。ほかの検索は、すべて元の =auth-source-search= に渡します。
- =gh= が使えない（ =executable-find= で見つからない）とき、または未ログインでトークンが空のときも、
  通常の auth-source の結果に戻ります。
- トークンの文字列は、ログにもメッセージにも出しません。 =:secret= には、呼ばれたときに値を返す関数を渡します。

*注意*

- トークンは、そのセッションの間、1 回だけ =gh= から取得して覚えます（ =vcs-forge--gh-token= ）。
  =gh auth refresh= でトークンを替えたあと、起動中の Emacs に反映するには、Emacs を再起動するか、
  この変数を =nil= に戻します。
- 認証に =gh= を使うのは、GitHub だけです。GitLab など、ほかのホストは、通常の auth-source の設定が要ります。


#+begin_src emacs-lisp
  ;;; vcs/vcs-forge.el --- Magit Forge 統合 -*- lexical-binding: t; -*-
  ;;
  ;;
  ;; Copyright (c) 2021-2026
  ;; Author: YAMASHITA, Takao
  ;; License: GNU GPL v3 or later
  ;;
  ;; Category: vcs
  ;;
  ;;; Commentary:
  ;;
  ;; GitHub/GitLab の Issue と Pull Request のための Magit Forge 統合。
  ;;
  ;; 本ファイルの責務:
  ;; - magit が利用可能になった後に forge をロードする
  ;; - GitHub の認証を `gh' （GitHub CLI）に任せる
  ;;
  ;; 認証の経路:
  ;; forge が使う ghub は、トークンを auth-source から「ホスト api.github.com、ユーザー
  ;; <github.user>^forge」で探す。通常は ~/.authinfo や pass にトークンを書いて用意するが、
  ;; ここでは `gh auth token' が出す、ログイン済みのトークンを返す。トークンを別の場所に
  ;; 複製せず、`gh auth login' / `gh auth refresh' だけで更新できる。`gh' が使えない、
  ;; または未ログインのときは、通常の auth-source の結果へ戻す。
  ;; トークンの文字列は、ログにもメッセージにも出さない。
  ;;; Code:

  (eval-when-compile (require 'leaf))

  (defvar vcs-forge--gh-token nil
    "Cached output of `gh auth token' for this session, or nil.")

  (defun vcs-forge--gh-token ()
    "Return the token printed by `gh auth token', or nil when unavailable."
    (or vcs-forge--gh-token
        (when (executable-find "gh")
          (let ((token (string-trim
                        (with-output-to-string
                          (with-current-buffer standard-output
                            (call-process "gh" nil '(t nil) nil "auth" "token"))))))
            (unless (string-empty-p token)
              (setq vcs-forge--gh-token token))))))

  (defun vcs-forge--auth-source-via-gh (orig &rest spec)
    "Around advice for `auth-source-search': answer GitHub forge lookups from gh.
  Only lookups for host api.github.com or github.com whose user ends in ^forge or
  ^ghub are handled.  Everything else, and every lookup when gh has no token,
  goes to ORIG with SPEC."
    (let ((host (plist-get spec :host))
          (user (plist-get spec :user)))
      (if (and (stringp host) (stringp user)
               (member host '("api.github.com" "github.com"))
               (string-match-p "\\^\\(forge\\|ghub\\)\\'" user)
               (vcs-forge--gh-token))
          (list (list :host host :user user
                      :secret (lambda () (vcs-forge--gh-token))))
        (apply orig spec))))

  (advice-add 'auth-source-search :around #'vcs-forge--auth-source-via-gh)

  (leaf forge :straight t :after magit)

  (provide 'vcs-forge)
  ;;; vcs/vcs-forge.el ends here
#+end_src
